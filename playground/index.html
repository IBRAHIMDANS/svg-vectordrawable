SVG to Android VectorDrawable

Paste or drop an SVG. Get the drawable XML, a side-by-side preview, and a warning for everything Android cannot draw.

  • Runs in your browser, nothing is uploaded
  • Gradients, clip-path and groups
  • Free and open source
  1. Paste or drop an SVG or pick an example under the input.
  2. Check the warnings and the preview they show what Android will draw, and what it cannot.
  3. Download the XML into res/drawable/ its file name is the resource name: use it as @drawable/name.

    Use the result in your app

    Save the downloaded file as app/src/main/res/drawable/icon.xml. Android names the resource after the file: lowercase letters, digits and underscores only, which the Download button already takes care of.

    Layout XML

    <ImageView
    android:layout_width="24dp"
    android:layout_height="24dp"
    app:srcCompat="@drawable/icon" />

    app:srcCompat (AppCompat) also works below API 24; android:src needs API 24 for gradients.

    Jetpack Compose

    Icon(
    painter = painterResource(R.drawable.icon),
    contentDescription = null,
)

    Icon tints the drawable with the content color; use Image to keep its own colors.

    API level

    Convert an SVG to see the API level it needs.

    Below API 24, gradients need AppCompat: vectorDrawables.useSupportLibrary = true in build.gradle, and app:srcCompat in layouts. Set minSdk in the options to get a warning.

    What converts

    A VectorDrawable cannot draw everything an SVG can. Nothing is dropped silently: whatever is not converted exactly shows up in the warnings.

    Converted exactly

    • Paths and shapes, fills and strokes (caps, joins, even-odd)
    • Groups and transforms; skew is baked into the geometry
    • Linear and radial gradients, gradientTransform included
    • clip-path, <use> and <symbol>
    • Dashed strokes, drawn as dash segments
    • Colors (hsl(), named, currentColor), opacity, viewBox

    Approximated, with a warning

    • Opacity of a group whose children overlap
    • Masks: converted to a clip when they are one, otherwise warned
    • Focal point of a radial gradient (fx / fy)

    Not possible in a VectorDrawable

    • <filter>, <image>, <pattern>, blend modes
    • <text> on this page (the package draws simple text from a font file)
    • For those, the command line can write a PNG instead: --fallback-png

    This page uses the lightweight build: <style> rules are not applied here, they are by the package (an inline style="…" works in both).

    Use it in your build

    This page runs the lightweight browser build. The package adds svgo normalization (inline <style> CSS, shape merging), batch conversion, a watch mode and PNG fallbacks.

    Command line

    npm install -D svg-vectordrawable
npx svgvd icons/ -o app/src/main/res/drawable

    Add --strict to fail the build on anything Android cannot represent.

    Node API

    import { convert } from 'svg-vectordrawable';

const { xml, warnings, minSdk } = convert(svg);

    Synchronous, typed, ESM and CommonJS. Also ships a browser build.
